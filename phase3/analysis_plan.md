# 識学 v2 Phase 3 Real-World Pilot Preregistration

Version 1.0.0 / Freeze date: 2026-08-09 JST

## 1. Phase 3の位置づけ

Phase 2の設計検出力・安全性監査では、6チーム/群は実地パイロットの下限であり、確認的な優越性主張に必要な規模ではないと判定した。したがってPhase 3は、実地での実装可能性、安全性、介入忠実度、ICC・分散・欠測率の把握、および予備的効果推定を目的とする。Phase 3単独で「識学が他施策より優越する」と結論してはならない。

## 2. 研究デザイン

5群のクラスター無作為化パイロット試験とする。群は、現状対照、KPIのみ、心理的安全性のみ、識学、統合の5群。無作為化単位は「同一の直属管理者を共有する最小管理クラスター」とし、一人の管理者が複数群を跨いで管理することを禁止する。

観察期間は4週間の無介入ベースライン + 12週間の介入。主要比較は識学群 - 現状対照群の1本に固定する。他群比較は探索的とする。

## 3. 4週間ベースライン

毎週、事前目標、実績、目標達成比、欠勤率、欠測率を取得する。第4週に心理的安全性尺度、離職意向率、チーム人数を取得する。12週間の介入期間に用いる目標は無作為化前に凍結する。業務上やむを得ず目標を変更した場合、旧目標と新目標を双方保存し、主要解析では旧目標を使用する。

## 4. 割付

4週ベースラインのチーム目標達成比で全適格クラスターを3分位に層別し、各層内で5群1:1:1:1:1の置換ブロック無作為化を行う。ブロックサイズは5。乱数seedは study_id + freeze_date_jst のSHA256ハッシュ先頭8桁を整数化して固定する。

## 5. 介入定義

識学群の介入要素は4点に限定する。

1. 一つの結果につき責任者を一人にする。
2. 期限と期限時の到達状態を明記する。
3. 責任と権限を一致させる。
4. レビューを「結果 - 差分 - 次の約束」で終了する。

恐怖、威圧、恫喝、暴言、個人攻撃、報復、暴力、屈辱を利用した圧力は識学介入に含めず、安全性事象として扱う。

KPIのみ群はKPI定義・可視化・定例レビューのみを追加する。心理的安全性のみ群は発言経路、失敗報告、学習レビュー、報復禁止を追加する。統合群は3要素を併用する。現状対照群は新規標準パッケージを追加しない。

## 6. 主要評価項目

主要アウトカムはチーム単位の12週累積凍結目標達成比とする。

Y = sum(actual_result weeks 1-12) / sum(frozen_target weeks 1-12)

主要Estimandは識学群と現状対照群のITT調整平均差。

主解析はチーム単位OLS ANCOVA:

Y12 ~ arm + baseline_ratio + randomization_stratum

95%CIはHC3 heteroskedasticity-robust CIを使用する。さらに実際の制約付き割付に従った100,000回のrandomization inferenceを実施し、両側p値を報告する。非有意を「効果なし」と解釈しない。

## 7. サンプルサイズ再計算

4週ベースラインをロックした後、無作為化前にICC、平均チーム人数 nbar、ベースライン相関 r を推定する。計画効果量は標準化 d=0.50、両側alpha=0.05、power=0.80に固定する。

m_raw = 2*(z_0.975 + z_0.80)^2*(1-r^2)*(1+(nbar-1)*ICC)/(nbar*d^2)

クラスター脱落率Lcを用いて

m_req = ceil(m_raw/(1-Lc))

とし、Lcは原則0.10、事前に観測可能な脱落見込みがより大きい場合はその値を用いる。必要数は max(6, m_req) チーム/群。必要数を確保できない場合、全適格チームでパイロットを継続するが、優越性主張は禁止する。

Phase 2の感度グリッドは、d=0.50でICC=0.15なら12チーム/群、ICC=0.40なら21チーム/群を80%支持確率の目安としていた。

## 8. 安全性Gate

安全性は成果から独立して判定する。安全性レビューは介入2、4、8、12週に行い、重大事象は常時監視する。

以下を定量レビューtriggerとする。

- 心理的安全性がベースライン比 -0.50 SD以下。
- 欠勤率が絶対値で +10 percentage points以上。
- 離職意向率が絶対値で +10 percentage points以上。

威圧、脅迫、暴言、個人攻撃、報復、暴力、屈辱的強制は即時pause事象とする。trigger発生時は該当クラスターの介入要素を一時停止し、データを保全して独立レビューを行い、継続・修正・停止を決定する。成果改善を理由に安全性triggerを無効化してはならない。

## 9. 介入忠実度

識学群では毎週、責任者一人、期限と到達状態、責任権限一致、結果-差分-次の約束の4項目を監査する。80%以上を適切実装とする。70%未満が2週連続した場合、因果解釈は実装失敗として保留する。

## 10. 停止条件

クラスター即時停止: 重大安全性事象、または独立レビューによる停止指示。

全試験停止: 同一介入に関連すると判断される重大安全性パターンが2クラスター以上で発生、または無作為化・目標凍結が重大に破損し再構成不能。

効果を理由とする早期停止は行わない。

## 11. 反証条件

実務的に意味のある最小効果を標準化 d=0.35とする。

識学の成果改善主張は、以下が全て成立したとき反証とする。

- 主要比較の95%CI上限が +0.35 SD相当未満。
- 識学群の忠実度が80%以上。
- 主要アウトカム完全率が90%以上。
- 重大な群間contaminationがない。

安全性両立主張は、独立レビューが介入関連の重大安全性事象を認定した場合、または心理的安全性 -0.50 SD、欠勤/離職意向 +10ppの悪化が次回レビューまで持続した場合に反証とする。

CIが0と+0.35 SDの双方を含む場合、低忠実度、欠測>10%、重大contaminationの場合は「未決定」とし、支持にも反証にも分類しない。

## 12. Phase 3終了判定

Confirmatory PhaseへのGO条件は、安全性未解決なし、識学忠実度80%以上、主要アウトカム完全率90%以上、主要効果推定の方向が識学有利、観測ICC等に基づく確認試験必要数が実行可能、の全てを満たすこと。

それ以外はHOLD。安全性両立主張の反証または重大データ完全性破損ではSTOPとする。

## 13. 報告義務

クラスターflow、群別baseline、ITT推定値とHC3 CI、randomization inference p値、安全性triggerとレビュー、週別忠実度、欠測、contamination、事前登録逸脱を必ず報告する。

禁止表現: 「識学の優越性を証明した」「p>0.05なので効果なし」「統合群が良いので相乗効果を証明した」。
